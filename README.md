# Python Day 142 - Budget Alert System

## About
A Python application that tracks expenses and compares monthly spending against a user-defined budget.

## Features
- Add and save expenses
- Read expense records from CSV
- Generate monthly budget reports
- Calculate category-wise spending
- Warn when 80% of the budget is used
- Alert when spending exceeds the budget

## Files
- `budget_alert.py` - Main program
- `expenses.csv` - Sample expense data

## How to Run
Keep both files in the same working directory and run:

`python budget_alert.py`

Choose option 2 and enter a month such as `2026-10`, followed by your budget.

## Concepts
CSV file handling, functions, dictionaries, lists, exception handling, and budget calculations.
